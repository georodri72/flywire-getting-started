FlyWire Getting-Started Guide (for beginners)

Last checked: Oct 27, 2026. Tested on Linux, Python 3, fafbseg 3.2.3, caveclient 8.2.1.

1. What FlyWire is

FlyWire is a free wiring map of an entire adult fruit fly brain: about 150K neurons and more than 50M synapses. The public release is called FAFB v783 (139,255 neurons). Source: https://codex.flywire.ai/

2. Pick your path

  • No code: browse and download tables in Codex (section 3).
  • Python: live queries, meshes and connections (sections 4–8).
  • Raw images or segmentation: tens of terabytes. Contact the team (see the maintainer's reply in https://github.com/seung-lab/FlyConnectome/issues/1).

3. No-code path: Codex

  1. Go to https://codex.flywire.ai/ and sign in with a Google account. Codex requires sign-in for rate-limiting. If you don't have a Google account, email flywire@princeton.edu.
  2. Search neurons or cell types in the browser.
  3. Download tables from https://codex.flywire.ai/api/download. A maintainer pointed people who wanted the "full dataset" there (https://github.com/seung-lab/FlyConnectome/issues/1).
  4. Also available without sign-in: the official v783 files on Zenodo at https://zenodo.org/records/10676866. They include proofread_root_ids_783.npy (1 MB), proofread_connections_783.feather (852 MB) and flywire_synapses_783.feather (9.5 GB).
  5. UNTESTED: the exact list of Codex downloads, because it sits behind sign-in.

4. Python setup

python3 -m venv flywire-env
source flywire-env/bin/activate        # Windows: flywire-env\Scripts\activate
pip install fafbseg caveclient

TESTED: installs fafbseg 3.2.3, caveclient 8.2.1 and navis 1.12.0 (https://pypi.org/project/fafbseg/).

5. Your token (the step that breaks most often)

  1. Log in at https://global.daf-apis.com/auth/api/v1/user/token with your FlyWire account and copy the token text.
  2. If it shows an empty [], open https://global.daf-apis.com/auth/api/v1/create_token instead. Note that a new token invalidates the old one, so reuse the same token on each computer (https://caveclient.readthedocs.io/en/latest/guide/authentication.html).
  3. Save it once:
from fafbseg import flywire
flywire.set_chunkedgraph_secret("PASTE_YOUR_TOKEN")

Source: https://fafbseg-py.readthedocs.io/en/latest/source/tutorials/flywire_setup.html - Where the file goes (resolved): both file names in the docs are valid. caveclient checks ~/.cloudvolume/secrets/cave-secret.json and also a server-specific ~/.cloudvolume/secrets/global.daf-apis.com-cave-secret.json (see default_token_name and server_token_filename in https://github.com/CAVEconnectome/CAVEclient/blob/master/caveclient/auth.py). The file content should be {"token": "YOUR_TOKEN"}. The quote typo in the fafbseg example is just a typo. - UNTESTED: saving and using a real token. I had none to test with.

6. Troubleshooting

Symptom Fix
No chunkedgraph/CAVE secret ... found No token saved yet. Do section 5. (TESTED: this is the exact error you get without a token.)
No Graphene authentication token was provided even though the token is "valid" (R on Windows) R and Python disagree about where your home folder is. Copy cave-secret.json into both C:/Users/<you>/.cloudvolume/secrets and C:/Users/<you>/Documents/.cloudvolume/secrets, as the maintainer suggested in https://github.com/seung-lab/cloud-volume/issues/534
Old token stopped working You made a new token somewhere else. Copy the newest one to every computer (caveclient docs above).

7. Pin your version (so results don't change)

Neuron IDs change as people keep editing the map. For results anyone can repeat, use the public dataset and materialization 783:

from fafbseg import flywire
flywire.set_default_dataset("public")    # TESTED, works without a token
# then pass materialization=783 to query functions, e.g.:
# flywire.synapses.get_connectivity(ids, materialization=783)

Sources: set_default_dataset and the flat_783 mapping in https://github.com/navis-org/fafbseg-py/blob/master/fafbseg/flywire/utils.py, and the materialization parameter in https://github.com/navis-org/fafbseg-py/blob/master/fafbseg/flywire/synapses.py. Codex notes that annotations update about weekly (https://codex.flywire.ai/about_flywire).

8. Three starter examples

A. Count the proofread neurons (no token needed). TESTED, prints 139255:

import numpy as np, urllib.request
url = "https://zenodo.org/records/10676866/files/proofread_root_ids_783.npy?download=1"
urllib.request.urlretrieve(url, "ids.npy")
ids = np.load("ids.npy")
print(len(ids), ids[:3])

B. Who connects to a neuron (token needed). UNTESTED past the token check:

from fafbseg import flywire
flywire.set_default_dataset("public")
print(flywire.synapses.get_connectivity(ids[:1], materialization=783))

C. Look at the official connection table offline (no token, 852 MB download). UNTESTED (too large for my test):

import pandas as pd   # pip install pandas pyarrow
df = pd.read_feather("proofread_connections_783.feather")
print(df.head())

Download it from https://zenodo.org/records/10676866.

9. Citing and terms

  • In publications, cite the papers listed on Codex's About page, and cite Codex itself as http://dx.doi.org/10.13140/RG.2.2.35928.67844 (https://codex.flywire.ai/about_flywire).
  • Using unreleased (pre-publication) data has separate rules. They're linked from the same page.
  • The FlyWire Terms of Service are linked from Codex sign-in. Main paper: https://www.nature.com/articles/s41586-024-07558-y
